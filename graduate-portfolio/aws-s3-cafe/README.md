# AWS S3 static cafe website hosting
Coursework in Cloud Concepts, Bradford College (2025–26). Built a static website and configured an AWS S3 bucket for hosting. The named student report documents a bucket policy, server-side encryption, versioning, lifecycle rules and replication to a secondary region for recovery. The source website HTML and CSS are included; original screenshot evidence was not published.
No live cloud billable infrastructure or current availability is claimed. The S3 endpoint from the report may no longer be active.
